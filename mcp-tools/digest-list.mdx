# digest_list

Get unactioned content from the digest queue. These are posts that need to be reviewed (saved, skipped, or marked for later).

## Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `platform` | string | No | Filter by platform: `x`, `instagram`, `tiktok`, `youtube`, `linkedin` |
| `limit` | number | No | Items per page (1-100, default: 20) |
| `offset` | number | No | Items to skip (default: 0) |

## Response Fields

### item

| Field | Type | Description |
|-------|------|-------------|
| `id` | string | Digest item UUID (use with `digest_action`) |
| `content.platform` | string | Platform name |
| `content.creatorHandle` | string | Creator's handle |
| `content.text` | string | Post text content |
| `content.title` | string | Post title (videos, articles) |
| `content.mediaUrls` | array | Image/media URLs |
| `content.videoUrl` | string | Video URL |
| `content.externalUrl` | string | External link |
| `content.metrics` | object | Engagement metrics |
| `content.postedAt` | string | Original post time |

### metrics

| Field | Type | Description |
|-------|------|-------------|
| `likes` | number | Like/heart count |
| `comments` | number | Comment count |
| `views` | number | View count |
| `shares` | number | Share/retweet count |

## Use Cases

- Review new content from subscribed creators
- Filter by platform for focused curation
- Find high-performing content to analyze
