# subscription_list

List all subscriptions in the workspace. Shows creator info, sync status, and content counts.

## Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `status` | string | No | Filter: `active`, `paused`, or `all` (default: `all`) |
| `limit` | number | No | Items per page (1-100, default: 50) |
| `offset` | number | No | Items to skip (default: 0) |

## Response Fields

### subscription

| Field | Type | Description |
|-------|------|-------------|
| `creatorId` | string | Creator UUID |
| `creator.handle` | string | Creator's handle |
| `creator.displayName` | string | Display name |
| `creator.platform` | string | Platform name |
| `creator.avatarUrl` | string | Profile image URL |
| `creator.followerCount` | number | Follower count |
| `isActive` | boolean | Whether subscription is active |
| `postLimit` | number | Max posts per ingestion |
| `dailyUpdates` | boolean | Daily sync enabled |
| `lastSyncedAt` | string | Last content fetch time |
| `createdAt` | string | Subscription creation time |

### pagination

| Field | Type | Description |
|-------|------|-------------|
| `total` | number | Total subscriptions matching filter |
| `limit` | number | Items per page |
| `offset` | number | Items skipped |
| `hasMore` | boolean | More items available |

## Use Cases

- See all creators you're following
- Check when content was last synced
- Find subscriptions that need attention
