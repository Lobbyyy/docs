# content_analyze

Analyze a piece of content using AI. Returns structured breakdown including hooks, main points, call-to-action, and writing style.

## Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `contentId` | string (UUID) | Yes | Content ID to analyze |

## Example

<CodeGroup>
```text Prompt
Analyze the post from levelsio about launching projects
```

    "result": {

## Response Fields

| Field | Type | Description |
|-------|------|-------------|
| `analysis.id` | string | Analysis UUID |
| `analysis.contentId` | string | Content that was analyzed |
| `analysis.model` | string | AI model used |
| `analysis.analysisType` | string | Type of analysis |
| `analysis.summary` | string | Brief content summary |
| `analysis.result` | object | Structured analysis |
| `analysis.tokensUsed` | number | AI tokens consumed |
| `analysis.createdAt` | string | Analysis timestamp |

### result.hook

| Field | Type | Description |
|-------|------|-------------|
| `type` | string | Hook type (credibility, curiosity, etc.) |
| `text` | string | The hook text |
| `effectiveness` | string | Effectiveness assessment |

### result.writingStyle

| Field | Type | Description |
|-------|------|-------------|
| `tone` | string | Writing tone |
| `voice` | string | Narrative voice |
| `techniques` | array | Writing techniques used |

<Note>
Analysis uses tokens from your plan's monthly allocation. Check `workspace_stats` to see remaining tokens.
</Note>
