# Quickstart

Get your Coconut MCP server connected to Claude Code.

## Prerequisites

- [Claude Code](https://claude.ai/claude-code) installed
- A Coconut account at [coconut.dev](https://coconut.dev)

## Step 1: Get Your API Key

1. Sign in to [coconut.dev](https://coconut.dev)
2. Go to **Settings** → **API Keys**
3. Click **Create API Key**
4. Copy the key (you'll only see it once)

<Warning>
Keep your API key secret. Never commit it to version control or share it publicly.
</Warning>

## Step 2: Configure Claude Code

Add Coconut to your Claude Code MCP configuration. Open your config file:

<CodeGroup>
```bash macOS
code ~/.claude/claude_code_config.json
```

```bash Linux
code ~/.claude/claude_code_config.json
```

```bash Windows
code %USERPROFILE%\.claude\claude_code_config.json
```
</CodeGroup>

Add the Coconut MCP server:

```json claude_code_config.json
{
  "mcpServers": {
    "coconut": {
      "type": "http",
      "url": "https://coconut.dev/api/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_API_KEY"
      }
    }
  }
}
```

<Tip>
Replace `YOUR_API_KEY` with the API key you created in Step 1.
</Tip>

## Step 3: Restart Claude Code

Restart Claude Code to load the new MCP configuration:

```bash
claude --mcp-debug
```

The `--mcp-debug` flag shows MCP connection status. You should see:

```
coconut: 11 tools available
```

## Step 4: Test the Connection

Ask Claude to check your workspace:

```
What's my Coconut workspace status?
```

Claude will use the `workspace_stats` tool to show your workspace overview.

## Troubleshooting

<AccordionGroup>
  <Accordion title="Claude Code shows 'Capabilities: none'">
    This usually means the Authorization header isn't being sent correctly. Check that:
    1. Your API key is valid (test it at coconut.dev/settings)
    2. The `Authorization` header uses `Bearer ` prefix (with a space)
    3. You've restarted Claude Code after changing config
  </Accordion>

  <Accordion title="'Authentication failed' errors">
    Your API key may be invalid or expired. Generate a new one at coconut.dev/settings.
  </Accordion>

  <Accordion title="Tools return 'workspace not found'">
    Make sure you have at least one workspace in Coconut. Sign in to coconut.dev and create a workspace if needed.
  </Accordion>
</AccordionGroup>
